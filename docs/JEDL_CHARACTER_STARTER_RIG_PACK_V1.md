# JEDL Character Master — starter rig pack v1

This starter pack is deliberately editable and independent from the motion engine.
It uses the existing `PuppetRig.HUMANOID` ten-bone hierarchy and draws each part
in the local coordinate space of its assigned bone.

## What ships in this iteration

The first appearance is a warm flat-vector prototype built into
`CharacterPartPainter`; it does not depend on downloaded art or external services.
The manifest is generated by `CharacterLayerContract.starterManifest()`.
Each entry is a replaceable layer with its own slot, bone, dimensions, pivot,
offset and draw order.

Included layers: head, ears, eyes, eyebrows, nose, mouth, back/front hair, cap,
neck, torso/shirt, pants, both upper arms and sleeves, both forearms and hands,
both thighs and shins, both shoes, glasses, chain, medal, watch, two drumsticks,
drum shell and drum stand.

## Rig bindings

| Rig bone | Attached visual parts |
|---|---|
| torso | torso, pants, chain, medal, drum, stand |
| head | head, ears, facial features, hair, cap, glasses, neck |
| armUL / armUR | upper arm and sleeve |
| foreArmL / foreArmR | forearm, hand, watch, drumstick |
| thighL / thighR | thigh |
| shinL / shinR | shin and shoe |

The preview path is: `PuppetEngine.poseFor()` → `PuppetRig.HUMANOID.solve()` →
`AvatarRenderer.draw()` → `CharacterLayerLibrary.draw()`. No second animation
engine or duplicated keyframe system is introduced.

## Coordinate contract

- Unit coordinates are normalized to each part's own rectangle.
- `pivotX/pivotY` are normalized anchors within that rectangle.
- `offsetX/offsetY` move a layer from its bone origin before scaling.
- `widthUnits/heightUnits` set the layer's size in rig units.
- `zIndex` sorts the resolved appearance back-to-front.
- `builtin://<id>` selects the included vector painter; `.png` paths select
  transparent Android asset bitmaps.
- Appearance color channels are `skin`, `hair`, `shirt`, `pants`, `shoes`.

## Current limitation

The built-in pack is a functional starter drawing, not the final bespoke JEDL
illustration. It proves the modular slots and rig attachment contract. PNG
replacement, alternate facial designs, finer hand poses and detailed percussion
props can be introduced slot-by-slot without changing the rig or motion clips.

## Validation boundary

JVM tests validate manifest integrity, coverage of all ten rig bones, ordering,
and single-slot replacement. CI must pass before calling this software milestone
green. A physical Redmi Note 10 preview is a separate required device check.
