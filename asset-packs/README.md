# JEDL offline asset packs

This directory contains the versioned catalog used by GitHub Actions to fetch
and verify optional offline asset packs.

A pack is added only after its exact source page, license text, commercial-use
permission, modification permission, and redistribution permission have been
checked. Commercial use alone is not enough: the license must also permit
redistributing the resource inside an offline JEDL pack.

The catalog is intentionally empty until a specific pack passes that review.
Do not add unpinned download URLs or guessed checksums.
